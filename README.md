# Перевірка джерел дисертації

Веб-застосунок для перевірки бібліографічних посилань, ручного пошуку потенційних джерел і порівняння двох академічних робіт.

## Режими роботи

### Перевірка джерел

Основний режим застосунку. Він знаходить список використаних джерел у завантаженому документі та визначає позиції, на які немає посилань у тексті. За потреби межі списку літератури можна уточнити вручну.

### Пошук джерел вручну

Доступний за адресою `/?mode=search` або через кнопку на головній сторінці. Режим приймає один PDF із текстовим шаром (до 30 МБ), виділяє змістовні фрагменти та готує відтворювані пошукові запити для зовнішніх систем. Можна зберігати проєкт, повертатися до запитів, відкривати пошукові посилання й фіксувати статус перевірки.

Застосунок не виконує автоматичний обхід пошукової видачі, не встановлює факт плагіату й не робить висновків замість експерта: пошук і оцінку результатів виконує користувач.

### Порівняння двох робіт

Доступний за адресою `/?mode=compare` або через кнопку на головній сторінці. Завантажте перевірювану дисертацію та ймовірне джерело у форматі PDF або DOCX (кожен файл — до 30 МБ). Режим показує точні та змінені текстові збіги, візуальне зіставлення фрагментів, покриття документа збігами й результати порівняння списків джерел.

Результати призначені для експертної перевірки. Система не визначає напрям запозичення й не робить автоматичного висновку про порушення академічної доброчесності.

### Підсвічування таблиці

Доступний за адресою `/?mode=table-highlight` або через верхнє меню. Режим
приймає готову двоколонкову таблицю у форматі DOCX, виділяє збіги жовтим і
відмінності бірюзовим, зберігає пояснення та активні посилання. Маркери
сторінок `С. …` у лівій і правій колонках вирівнюються, щоб експерт міг зручно
зіставляти фрагменти.
У всьому документі застосовуються обрані шрифт і розмір, чорний текст без
жирності, курсиву, підкреслення та попередньої кольорової заливки. URL залишаються
активними; жовта й бірюзова підсвітка додається лише до результатів порівняння.
Бібліографія розташовується над спільним рядком маркерів без видимої роздільної
лінії: довжина URL і переноси не впливають на їхнє вирівнювання. Діапазон рядків
в інтерфейсі рахує записи порівняння, включно з їхніми службовими шапками.

### Очищення звіту Plag

Доступний за адресою `/?mode=plag-filter` або через верхнє меню. Режим приймає
звіт Plag у форматі PDF (до 30 МБ) і прибирає з нього збіги, що не є
плагіатом: власні попередні публікації автора, цитування автора чужими
роботами та джерела, опубліковані пізніше за дисертацію. Прізвище, ім'я, по
батькові й рік дисертації розпізнаються з титулу самі — досить підтвердити їх
одним натисканням, після чого джерела перевіряються паралельно без повторних
кліків. Далі — підсумок двома блоками (виключено / залишено) з кнопкою
завантаження та перегляд аркуш за аркушем з наложенням прямо на зображення,
де джерело можна залишити чи виключити вручну. Проєкт (JSON) зберігається й
відновлюється в згорнутому блоці внизу екрана. Очищений PDF містить протокол
з переліком причин виключення кожного джерела — вихідні відсотки й оцінки
Plag на початкових сторінках звіту не перераховуються.

### Звіт

Доступний за адресою `/?mode=report-first-page` або останнім пунктом верхнього
меню. Завантажте один автореферат PDF із текстовим шаром до 30 МБ: одразу
з'явиться HTML сформованої початкової сторінки звіту та кнопка завантаження
DOCX. Під ними розташовано згорнутий блок «Уточнити дані»; кожна правка одразу
оновлює обидва результати. ПІБ автора переноситься без відмінювання; невідомі
поля позначаються `_____`. Експерт постійний, місяць і рік — за часом Києва.

Заголовкова частина — Calibri Light 22 pt (зменшення погоджено користувачем
21.10.2026 для вміщення повних даних), інший текст — Calibri 14 pt. Перед
рядком дати додано інтервал 17 pt, приблизно один порожній рядок. У шести
контрольних прикладах результат займає одну сторінку MS Word; довільні значно
довші реквізити можуть займати більше. HTML передає зміст та оформлення,
але не перевіряє пагінацію Word. OCR, пакетна обробка, аналіз плагіату й
експорт PDF не виконуються. Дані обробляються локально детермінованими
правилами, без LLM та зовнішніх сервісів.

Робочий шаблон постачається в `report_first_page/resources/`; каталог
`examples/` для запуску не потрібний. Відтворення шаблону зі зразка:

```bash
python tools/build_report_first_page_template.py "шлях/до/зразка.docx" report_first_page/resources/report_first_page.docx
```

## Можливості

- Завантаження `.pdf` і `.docx` файлів (до 30 МБ)
- Автоматичне знаходження розділу «Список літератури»
- Ручний режим вказівки розташування списку
- Підтримка багаторядкових записів і двох форматів нумерації (`1.` та `[1]`)
- Розгортання діапазонів посилань (`[15–18]` → 15, 16, 17, 18)
- Таблиця сиріт з повним текстом кожного джерела
- Рядок номерів для копіювання в одне поле

## Структура проєкту

```
dissertation-checker/
├── app.py                  # Streamlit UI
├── ui_helpers.py           # чиста логіка шару UI (тестується без Streamlit)
├── compare/                # підготовка, пошук і відображення збігів двох документів
├── search/                 # побудова запитів і стан ручного пошуку джерел
├── table_highlighter/      # підсвічування готової порівняльної таблиці DOCX
├── report_first_page/      # початкова сторінка звіту з автореферату PDF
├── parser/
│   ├── __init__.py
│   ├── types.py            # спільні типи, константи, предикати
│   ├── extractor.py        # PDF/DOCX → рядки; автор і рік з титулки
│   ├── bibliography.py     # поділ на зони, парсинг записів
│   ├── citations.py        # пошук посилань [N] у тексті
│   ├── year_extractor.py   # рік видання джерела
│   ├── dstu_validator.py   # перевірка ДСТУ 8302:2015
│   ├── paragraph_analyzer.py  # абзаци без посилань
│   └── highlighter.py      # підсвітка посилань у PDF
├── tests/                  # pytest
├── requirements.txt
├── requirements-dev.txt
└── README.md
```

## Локальний запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

Після запуску доступні також окремі адреси:

- `http://localhost:8501/?mode=search` — ручний пошук джерел;
- `http://localhost:8501/?mode=compare` — порівняння двох робіт.
- `http://localhost:8501/?mode=table-highlight` — підсвічування таблиці DOCX.
- `http://localhost:8501/?mode=report-first-page` — початкова сторінка звіту.

## Деплой на Streamlit Community Cloud

1. Завантажити репозиторій на GitHub (публічний або приватний).
2. Відкрити [share.streamlit.io](https://share.streamlit.io) → **New app**.
3. Обрати репозиторій, гілку `main`, файл `app.py`.
4. Натиснути **Deploy**.

Ресурси безкоштовного тіру (~1 ГБ RAM) достатньо для обробки дисертацій до 30 МБ.

## Тести

```bash
pip install -r requirements-dev.txt
pytest
```

`pytest` запускає весь набір і одразу міряє покриття (поріг — 90 %).
Зразки PDF/DOCX для тестів будуються в пам'яті (`tests/conftest.py`),
контрольні автореферати для корпусних перевірок звіту читаються локально
з `examples/avtoreferats/`. Робочий шаблон DOCX входить до нового пакета.

## Ліміти та обмеження

| Параметр | Значення |
|---|---|
| Максимальний розмір файлу | 30 МБ |
| Формати | `.pdf`, `.docx` |
| Старий `.doc` (бінарний Word) | Не підтримується — треба пересейвити як `.docx` |
| Скан-PDF (без текстового шару) | Не підтримується |
| Пакетна обробка | Не підтримується |
| Експорт сторінки звіту | `.docx` |

### Що враховано з реальних дисертацій

- **Автонумеровані списки Word.** Номери елементів списку зберігаються в
  `numbering.xml`, а не в тексті абзацу, тому бібліографія, оформлена списком,
  приходить із `python-docx` зовсім без номерів. Номери відновлюються — інакше
  список не парситься взагалі.
- **Кілька заголовків списку в одному документі.** Якщо після українського
  списку йде англомовна анотація зі своїм «REFERENCES» або є поглавні списки,
  обирається той заголовок, чия зона дає найбільше записів, а не просто
  останній.
- **Повторення заголовка колонтитулом** на кожній сторінці бібліографії.
- **ЗМІСТ на табуляції або пробілах**, без крапкових лідерів.

## Формат посилань (підтримується)

| Приклад | Результат |
|---|---|
| `[1]` | джерело 1 |
| `[1, 15]` | джерело 1 (15 — сторінка) |
| `[1; 3; 7]` | джерела 1, 3, 7 |
| `[15-18]` або `[15–18]` | джерела 15, 16, 17, 18 |
| `[1, 15; 3; 5, 20-25]` | джерела 1, 3, 5 |
